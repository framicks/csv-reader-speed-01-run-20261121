A fast, dependency-free drop-in for csv-reader 1.0.0: it reads broken CSV files exactly the way csv-reader does — same columns, rows and errors for every case, byte for byte — but with a single-pass scanner that slices fields out of the text instead of building them character by character, so it runs measurably faster on large files.

## Run it

```sh
node main.ts
```
